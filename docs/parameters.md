# Параметры и допущения

Источник всех значений — [`params.yaml`](../src/tram_odometry/config/params.yaml).
[`load_params`](../src/tram_odometry_core/tram_odometry_core/types.py) читает вложенность
`/**.ros__parameters`, требует каждый ключ и отвергает неизвестные ключи и неверные
типы. Ниже перечислены **все 45** конечных ключей файла на текущем `origin/main`.
Параметры фильтра, чья реализация относится к открытой #11, отмечены отдельно.
Числа следует сверять с YAML: это описание смысла, не второй источник настроек.

| Ключ | Единица, смысл и текущее использование |
|---|---|
| `frames.map` | Имя локальной системы ENU для `Odometry.header.frame_id`; по умолчанию `map`. Использует ROS-обёртка. |
| `frames.base` | Имя системы вагона для `Odometry.child_frame_id` и `VelocitySensor.header.frame_id`; `base_link`. |
| `input.wheel_speed_scale` | Множитель км/ч → м/с (`1/3,6`), применяется один раз в `Preprocessor._wheel`. |
| `input.stale_timeout_s` | Секунды допустимого молчания тележки; старше этого `SlipDetector.update` ставит доверие 0. |
| `input.max_wheel_accel_mps2` | м/с², предел выброса производной колеса в `Preprocessor._wheel`; исключение — переход к/от ровно нулевой скорости, чтобы обнаружить застрявшую тележку (D-031). |
| `input.max_stamp_jump_s` | с, `10`: stamp тележки или контроллера дальше этого впереди самого нового принятого считается сбоем часов и отбрасывается, пока следующий сэмпл не подтвердит скачок (другой поток рядом с тем же stamp или тот же поток, идущий дальше); stamp дальше этого позади гейта своего потока, подтверждённый так же, переставляет гейт назад (#77, D-043). В данных наибольший скачок вперёд — 2,6 с (122 bag), запас ×4. |
| `vehicle.mass_kg` | кг, заглушка 40 000; сейчас моделью не читается. Сила и масса раздельно по этим измерениям не идентифицируются, таблица ускорений задаётся напрямую. |
| `vehicle.wheel_scale_front` | Безразмерная поправка радиуса переднего колеса после перевода единиц; применяется в `Preprocessor._wheel`, сейчас фиксированное значение, онлайн-оценки нет. |
| `vehicle.wheel_scale_rear` | То же для заднего колеса; применяется в `Preprocessor._wheel`, сейчас фиксированное значение. |
| `drive.notch_max` | Максимальный модуль команды (`15`), задаёт число строк таблиц `0…15`; форму проверяет `types._validate_drive`, ограничение команды применяет `dynamics.model_accel`. |
| `drive.speed_grid_mps` | м/с, строго возрастающие узлы скорости от 0 до 16 с 11 узлами, идентифицированы по train в #9 (D-033); `dynamics.model_accel` интерполирует ускорение линейно, за краями берёт крайнее значение. |
| `drive.traction_accel_table` | м/с², неотрицательные модули тягового ускорения, row-major `notch × speed_grid_mps`, нулевая строка из нулей; значения идентифицированы по train без явной коррекции уклона (D-033), применяются в `dynamics.model_accel` (#10, D-036). |
| `drive.brake_accel_table` | м/с², неотрицательные модули тормозного ускорения в том же порядке; значения идентифицированы по train без явной коррекции уклона (D-033), применяются в `dynamics.model_accel` (#10, D-036). |
| `drive.adhesion_accel_mps2` | м/с², верхняя граница модуля ускорения по сцеплению (`1,59`, D-033); применяется в `model_accel` (D-036); валидируется; расчёт применяет. |
| `drive.traction_power_w_per_kg` | Вт/кг = м²/с³, предел удельной мощности тяги (`8,5`, D-033); применяется в `model_accel` (D-036). Это не измеренный момент двигателя. |
| `drive.response_delay_s` | с, задержка отклика привода: таблицы подогнаны к позиции контроллера `notch(t − 0,3)` (D-033); `pipeline` берёт позицию из кольцевого буфера команд с этой задержкой (D-036). |
| `drive.use_model` | флаг: `true` — при молчании обеих тележек дольше `input.stale_timeout_s` скорость прогнозируется по `model_accel`, а `accel_model` передаётся детектору; `false` — прежнее удержание скорости (D-021), модель не вызывается. |
| `resistance.c0` | м/с², постоянная часть эффективного сопротивления Дэвиса, `0,00526` по выбегу train без явной коррекции уклона (D-033); вычитается в `dynamics.model_accel` (#10, D-036). |
| `resistance.c1` | с⁻¹, коэффициент при скорости в сопротивлении Дэвиса; вычитается в `dynamics.model_accel`, сейчас 0. |
| `resistance.c2` | м⁻¹, коэффициент при квадрате скорости в сопротивлении Дэвиса; вычитается в `dynamics.model_accel`, сейчас 0. |
| `filter.rate_hz` | Гц, проектная частота (`40`); фактически нода публикует на каждом принятом входе, отдельного таймера нет. |
| `filter.q_accel` | `(м/с²)²·с`, спектральная плотность белого шума ускорения; по контракту вклад в дисперсию скорости за `dt` равен `q_accel·dt` (D-032), расчёт появится после #11. |
| `filter.r_wheel` | `(м/с)²`, дисперсия скорости одной исправной тележки; по D-032 эффективная дисперсия при доверии `trust > 0` равна `r_wheel/trust`. Сейчас это базовая дисперсия `Estimate`; EKF ещё не влит. |
| `filter.q_bias` | `(м/с²)²/с`, спектральная плотность случайного хода медленного смещения ускорения (D-032); ключ для открытой #11, пока не влияет на расчёт. |
| `filter.initial_bias_var` | `(м/с²)²`, начальная дисперсия смещения ускорения (D-032); ключ для открытой #11, пока не влияет на расчёт. |
| `filter.nis_gate` | Безразмерный включительный порог NIS (`9`); по D-032 измерение выше порога должно отклоняться, реализация относится к открытой #11. |
| `slip.front_rear_threshold_mps` | м/с, базовый допуск расхождения двух тележек (`0,5`) в `SlipDetector.update`. |
| `slip.model_residual_threshold_mps2` | м/с², рост допуска с `dt` (`1,0`) в `SlipDetector.update`; это порог, а не измеренное ускорение. |
| `position.map_file` | Имя карты `route.csv` внутри `share/tram_odometry/maps`; `load_route` также читает `stops.csv` рядом, если он есть. |
| `position.use_map` | Логический переключатель карты: `true` — `PathTracker`, `false` — прямая по начальному курсу. |
| `position.join_m` | м, максимальный разрыв для продолжения ветки карты на её конце (`15`). |
| `position.along_drift_frac` | Безразмерная 1σ ошибка вдоль пути на метр после якоря (`0,01`); ковариация растёт с пробегом. |
| `position.cross_std_m` | м, постоянная 1σ поперёк пути (`0,5`) в ковариации `PathTracker.advance`. |
| `position.fix_gate_m` | м, удалённость fix окна от всей карты, после которой fix отклоняется (`50`); защита от выброса GNSS. |
| `position.anchor_std_m` | м, начальная 1σ неопределённость положения вдоль пути сразу после GNSS-выставки (`3`); квадрат задаёт начальную дисперсию `PathTracker`. |
| `position.stop_speed_mps` | м/с, порог покоя (`0,3`), используемый `Odometry._on_standstill` для начала отсчёта стоянки. |
| `position.stop_min_s` | с, минимальная длительность стоянки (`5`), после которой однократно предлагается привязка к месту; в окне GNSS она отключена. |
| `position.stop_snap_max_m` | м, максимальное расстояние вдоль дуги до места (`20`); дальше стоянка трактуется как сигнал, путь не корректируется. |
| `position.stop_std_m` | м, 1σ неопределённость места остановки (`2`), задаёт вес взвешенной коррекции `s`. |
| `position.scale_alpha` | Безразмерный вес онлайн-обновления масштаба (`0,3`) по отношению пути карты к пути колёс между двумя стоянками. |
| `position.scale_max_dev` | Безразмерная максимальная поправка масштаба (`0,03`): оценка ограничивается диапазоном `1 ± 3 %`. |
| `position.scale_min_arc_m` | м, минимальная дуга между остановками на одной ветке (`300`), чтобы использовать пару для обновления масштаба. |
| `gnss.init_window_s` | с, разрешённое окно начальной выставки от первого `header.stamp` (`5`); `Odometry._in_window`. |
| `gnss.topic_fix` | Имя входного топика master fix; используется нодой и `Odometry.step`. |
| `gnss.topic_vel` | Имя входного топика master vel; курс запасного режима в `Odometry._on_vel`. |

## Допущения и пределы применимости

- Колёса дают модуль скорости, знак заднего хода не различим. Карта движется по
  выбранной ветке вперёд; на другом маршруте или при неверной ветке ошибка растёт.
- Карта построена офлайн из train, GNSS после окна не используется в оценке.
  Начало ENU — первый fix master со статусом GBAS в окне, иначе первый валидный.
- Рельсовый уклон, радиус колеса, передаточное отношение и момент двигателя
  напрямую не наблюдаются имеющимися входами. `wheel_scale_*` — эмпирические
  поправки, а не измеренный радиус; `mass_kg` пока не участвует в расчёте.
- При молчании обеих тележек скорость прогнозируется моделью привода, если
  `drive.use_model: true`; при `false` сохраняется предыдущее значение. Ошибка
  прогноза зависит от таблицы привода, задержки и неучтённого уклона.
- `filter.rate_hz` не ограничивает частоту фактических публикаций; её надо мерить
  на стенде, как и задержку и память.
