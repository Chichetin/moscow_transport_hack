### Почему позиция не восстанавливается при ошибке масштаба

```bash
.venv/bin/python tools/eval/experiments/snap_diag.py out/eval/141-holdout-v2/stress.json
```

Привязка к остановкам (D-034) **теряет захват**. Пример `30618_3e9f4952`, `scale_up`: расстояние
оценки до ближайшего места остановки на стоянках — 3, 1, 2, 5, 2, 5, затем 22, 25, 27, 32, 33,
36, 38, 42, 44, 45 м. Первый промах больше `position.stop_snap_max_m` = 20 м, дальше ошибка растёт
монотонно: онлайн-масштаб обновляется только между двумя принятыми привязками, а принять их
мешает тот же фиксированный порог. Привязано 6 из 17 стоянок (в чистом прогоне 16 из 17).
Такой же хвост промахов есть и **в чистых прогонах** bag 30639 (`0be558e2`: 5 промахов из 15,
`d927f360`: 4 из 9), то есть это касается не только синтетики. Область `core-position` —
передано владельцу комментарием, в ядре здесь ничего не менялось.
