## Воспроизведение

Из отдельного чистого worktree на этом commit с исходным `scale_alpha: 0.3`:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python tools/eval/run_eval.py --split holdout --out out/eval/scale-alpha-03-ceffa58 > out/scale-alpha-03-ceffa58.md
# Поменять только position.scale_alpha в params.yaml: 0.3 -> 0.0.
.venv/bin/python tools/eval/run_eval.py --split holdout --compare out/eval/scale-alpha-03-ceffa58/metrics.json --out out/eval/scale-alpha-00-ceffa58 > out/scale-alpha-00-vs-03-ceffa58.md
# Вернуть position.scale_alpha: 0.0 -> 0.3.
```

## Вывод и пределы

На этом holdout отключение онлайн-обновления ухудшает обе главные метрики положения; оставляем `scale_alpha=0.3`. Шум отдельного отношения расстояний не делает оценку бесполезной в совокупности, но регрессия на `30618_27e994fc` показывает, что отдельные пары остановок могут навредить. Эта абляция не измеряет дисперсию самих отношений, не доказывает оптимальность `0.3` и не заменяет стенд жюри. Holdout уже использовался для решений о merge; здесь сравнивались только два заранее выбранных значения без подбора нового коэффициента.
