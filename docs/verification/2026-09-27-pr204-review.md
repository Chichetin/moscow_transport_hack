`output.py:98–109`: `_held` не очищается при возвращении нормального offset. Для `RunGate(10)` подать vehicle=True с парами `(stamp, monotonic)`:

`(1000,0), (2001,1), (1002,2), (2011,11), (1012,12), (2021,21), (1022,22)`.

Фактические verdict: **run / hold / run / hold / run / new / drop**. Это три одиночных ошибки stamp, между которыми идут правильные сообщения.
