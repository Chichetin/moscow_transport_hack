## Ошибка и правка

`pipeline._estimate` переносил скорость состояния на stamp запоздалого колеса:
`max(0, v − a·(now − t))`. На стоянке под тормозом `a = a_model(notch, 0) + b < 0`, а
состояние обрезано в 0, и выход колеса был `|a|·лаг`. Воспроизведение ревьюера (обе тележки
0 км/ч 20 с, контроллер впереди колёс на лаг):

| позиция | a(0), м/с² | лаг, с | выход до правки, м/с | после |
|---:|---:|---:|---:|---:|
| 0 | −0,005 | 1,0 / 3,7 | 0,005 / 0,019 | 0 / 0 |
| −5 | −0,471 | 1,0 / 3,7 | 0,471 / 1,744 | 0 / 0 |
| −15 | −1,414 | 1,0 / 3,7 | 1,414 / 5,233 | 0 / 0 |

Правка: `Odometry` помнит `t_zero` — момент, когда скорость состояния дошла до 0, и
`a_zero ≤ 0` — ускорение, с которым она остановилась. `t_zero` — пересечение нуля линией
торможения на шаге `t_prev + v_prev/−a`, не позже `now`; с начала прогона и после ресинка часов
— `−inf` («стоит всегда»). Выход: едет — как раньше; стоит — 0 при `t ≥ t_zero`,
`−a_zero·(t_zero − t)` раньше. Тормоз модели на стоянке — не движение, назад его не
интегрируем; движение до остановки — интегрируем с тем торможением, с которым оно было.

Остаточное (синтетика, не регресс относительно `main`): торможение до стоянки при лаге 3,7 с —
фильтр доводит состояние до 0 на 4 с позже колёс (смещение учит +0,5 м/с² против модели), и
отсчёты колёс, стоящих уже 0 м/с, выходят с 0,34 → 0 м/с за 3,7 с (`a_zero` −0,10 м/с²). До
правки (`1382dfd`) — растёт до 5,23 м/с на том же отрезке; `main` (`0f05f15`, выход — скорость
состояния на 3,7 с впереди) даёт 0 после остановки, но на самом торможении ошибается на
+1,3…+2,1 м/с (ветка — +0,15…+0,25). Тест `test_late_wheel_braking_to_a_stop_keeps_its_own_speed`
держит допуск 0,6 м/с.
