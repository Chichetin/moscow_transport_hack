# Журнал решений

Одна строка — одно решение: что выбрали, почему, что отвергли. Это готовые ответы на
«почему так» для документов сдачи и питча. Задним числом не переписываются: изменилось —
новая строка со ссылкой на прежнюю. Номер берёт тот, чей PR вливается; при конфликте
номеров в двух PR второй перенумеровывает свой.
