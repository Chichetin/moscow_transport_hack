# Матрица соответствия условиям

Каждый пункт `task.md` и README данных → чем закрываем → как проверить → статус.
Разовая оценка `jury` не заменяет живую таблицу, видную всем.

- Статус: `—` не начато, `⚠️` частично или без доказательства, `✅` закрыто.
  `✅` — только со ссылкой на commit, тест, файл или запись в `docs/verification/`.
- Появился артефакт — строка обновляется в том же PR.
- Перед чекпоинтом: таблица сверху вниз → `jury` → скилл `submission-checklist`.
