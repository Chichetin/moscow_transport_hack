# Питч

Материалы к полуфинальному питчу (критерии `task.md`: выступление и демонстрация 10,
глубина 12, ответы 8). Пакет PITCH1 плана, issue #22.

| Файл | Что |
|---|---|
| [`script.md`](script.md) | сценарий на 6 минут с таймингом по слайдам, тезисы, чего не говорим, графики к слайдам, демо, чек-лист репетиции |
| [`qa.md`](qa.md) | 15 вопросов жюри (`jury`, режим 2) с ответами и ссылками на репозиторий; отдельно — вопросы, на которые ответ слабый, и что сделать до питча |

Источники чисел — `docs/verification/` и `docs/accuracy.md`; модель — `docs/model.md`;
параметры — `docs/parameters.md`; ограничения — `docs/roadmap.md`. Перед питчем числа
пересчитываются на commit сдачи (V1, #19), графики прогона — E3 (#16).
