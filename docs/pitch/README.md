# Питч

Материалы к полуфинальному питчу (критерии `task.md`: выступление и демонстрация 10,
глубина 12, ответы 8). Пакет PITCH1 плана, issue #22 (закрыта); материалы актуализированы
вручную на `main`, последняя правка — commit `4bfc3b0`, 2026-09-27 (после развилки у депо
#138/D-074, точки `base_link` #142/D-077, масштаба скорости #153/D-082 и сетки MGRS
#155/D-083).
