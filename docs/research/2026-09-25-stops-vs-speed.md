# Остановки по профилю скорости колёс против карты остановок (#58)

Гипотеза: остановки, найденные **только по колёсам** (`v < 0,1 м/с` не менее 3 с, без GNSS в
детекции), совпадают с местами остановок маршрута из `maps/stops.csv` (построены из GNSS
train, #56/D-034). Если да — PO2 может искать место остановки без GNSS в контуре.

## Метод

`notebooks/identification/stops_vs_speed.py`:

1. Скорость — среднее тележек (`front`/`rear`, км/ч → м/с, без масштаба по трамваю), взято
   «удержанием последнего значения» на объединённой сетке отсчётов обеих тележек — так же,
   как видит их фильтр.
2. Остановка колеса: непрерывный отрезок `v < 0,1 м/с` не короче 3 с (`wheel_stop_stretches`,
   без GNSS).
3. Истинное положение остановки: медиана GNSS master fix (статус 2, иначе все) внутри окна
   остановки, спроецированная на `route.csv` — **тот же метод**, что строит `stops.csv`
   (`tools/pathgraph/build_stops.py`), так что сравнение честное (не разная методика).
4. Расстояние до ближайшего места того же branch в `stops.csv`; branch без единого известного
   места (не в стороне это не обязательно означает 0 м) размечены отдельно.
5. Признаки только из разрешённых входов для отделения «остановка на месте» от «пауза не на
   месте»: длительность, пройденное расстояние по колёсам от предыдущей остановки, |изменение
   позиции контроллера| в окне ±5 с вокруг остановки.

```bash
.venv/bin/python notebooks/identification/stops_vs_speed.py --split train
.venv/bin/python notebooks/identification/stops_vs_speed.py --split holdout   # только отчёт
```

## Вывод

**Берём порог `stop_snap_max_m = 20 м` без изменений** — он уже используется в PO2 (#56,
D-034) и независимо (другая методика детекции: колёса, а не Доплер GNSS) подтверждён числом
80–83 % с train на holdout. Признаки out of GNSS (длительность, смена позиции контроллера)
слабо разделяют «рядом»/«не рядом» — самостоятельный классификатор без GNSS строить не
имеет смысла, порог расстояния и без него работает: **PathTracker уже привязывает по дуге от
GNSS-якоря выставки**, а не заново ищет место по чистому wheel-only сигналу, так что отдельный
классификатор не нужен — пробег от предыдущей остановки (221 против ~50–120 м) можно
использовать как дополнительный гейт против частых пауз, если ложные привязки станут заметны
на стрессе (#15) или в разборе худших bag (#16).

## Ограничения

- Скорость колеса здесь — сырая, без масштаба по трамваю (`wheel_scale_front/rear`) и без
  предобработки (`Preprocessor`): для порога `< 0,1 м/с` разница не важна.
- «Известное место» — кластер ≥ 5 bag (`MIN_BAGS` в `build_stops.py`); одиночные остановки
  (светофор конкретного прогона) в `stops.csv` нет и не могут быть «рядом» по определению —
  часть 20 % «не рядом» это ожидаемо, а не ошибка метода.
- 14 (train) / 2 (holdout) остановок — на branch без единого известного места (короткие
  ветки-тупики с < 5 train bag): расстояние не определено, не входит в проценты выше.
