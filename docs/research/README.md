# Исследования

Заметки по литературе и вариантам модели: тяговый привод трамвая (характеристика по
позициям контроллера), продольная динамика и сопротивление движению, детекторы
проскальзывания/юза, EKF с адаптивным шумом измерений, привязка к карте. Одна заметка —
один файл с источниками и выводом «что берём / что нет» (итог — строкой в `docs/decisions.md`).
