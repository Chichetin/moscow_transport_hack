# tools/stand — замеры реального времени по записи стенда жюри

По записи `docker/jury-stand.sh` (`out/stand/<bag>/record`, `resources.txt`) считает:
задержку вход → выход (сопоставление выхода с входом по `header.stamp`, задержка =
время приёма выхода − время приёма входа), p50/p99/max; частоту каждого `/result/*`;
CPU % и пиковый RSS ноды, рост RSS во времени. Порог — критерий 4 `task.md`.

Статус: **не реализовано** — пакет плана `stand: замер задержки и ресурсов`.
