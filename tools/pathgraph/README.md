# tools/pathgraph — карта маршрута из GNSS train

Строит `src/tram_odometry/maps/route.csv` (формат — `docs/contracts.md` §5) из GNSS master
прогонов **train** (`tools/eval/splits.yaml`): фильтр выбросов и статуса, выделение двух
направлений и петель, усреднение проходов, ресэмплинг по дуге с шагом ≤ 2 м. Разрешено как
офлайн-калибровка (D-007). Holdout не используется.

Статус: **не реализовано** — пакет плана `map: карта маршрута`.
